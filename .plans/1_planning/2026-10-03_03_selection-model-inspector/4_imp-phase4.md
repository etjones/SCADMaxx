Covers all SI requirements as integrated behavior. No later feature is required to pass this phase.

1. Complete native renderer/DPI and input cases from earlier phases on the feature's declared base. Exercise invalid
   source and changes in a dirty included file while a pick is pending; there must be no delivery of a stale hit.
2. Verify shaders install through CMake and are found in an extracted feature build. Test Inspector visibility and
   existing shortcuts/themes without adding dependencies merely for cosmetic consistency.
3. Rehearse the feature-only delta against the selected SCADMaxx inputs in an isolated composition when that check
   is authorized; no enabled-stack or promotion edits. Record source/control-owned changes separately.
4. Record DTOs, shader capabilities, unsupported modes, exact base/head and actual passing cases in the standard
   completion notes. Freeze this API for 06/14/04. Do not claim a later consumer tested merely because it can compile.

Exit: all named unit/native checks pass with real test discovery; package resources verified; no future consumer
imports or duplicate document/result ownership. Full application delivery remains the explicit integration workflow.
